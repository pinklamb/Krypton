Command reference

Command reference

Everything the krypton command can do.

Usage

krypton [paths ...] [options]

Paths are files or folders. Reported file names are relative to the first path if it is a folder, otherwise to the current folder.

Options

OptionWhat it does
--top NRows in the function ranking. 0 prints none.
--base REFScore only files and lines changed since a git ref.
--config FILE.tomlOverride any engine setting. See Configuration.
--jsonPrint the full result as JSON and nothing else.
--level relaxed|standard|strictHow strict the flag limit is. Default standard.
--history FILE.jsonlLog this run there (the file is created) and report progress since the last one.
--order-by-volatilityPrint a JSON manifest of files, most stable first, instead of the report.
--volatility FILE.jsonUse a map of path to change count instead of git history.

Exit codes

CodeMeaning
0Success.
1The purity score fell below the failure line.
2Usage error: no files, or a bad config or volatility file.

JSON output

krypton src --json

Prints the full result. The main fields:

FieldContents
purity_score0 to 100 for the run.
check_conclusionsuccess or failure.
findingsOne entry per file: filename, logic_complexity_rating, flagged, flag_reason, nesting_score, max_depth, effective_lines and a functions list.
hints{"file:line function": "advice"}, heaviest first.
errors{error code: explanation} for files too large to analyze, with the setting that would include them.
progressFilled when --history is used.
summary_markdownA summary ready to post as a pull request comment.

Configuration

--config krypton.toml accepts any engine setting as name = value. The most useful ones:

max_file_bytes = 3000000      # include larger files
coupling_weight_threshold = 25  # example value: how many linked files make a hotspot

Settings are listed in argon/engine/config.py. A tsconfig.json or jsconfig.json next to the scanned folder is read so path aliases resolve.

What gets scanned

  • .js .jsx .mjs .cjs .ts .tsx .mts .cts .py
  • Inside a git repository, anything .gitignore ignores is skipped.
  • Vendored and generated paths are skipped by default.
  • Files whose real path leaves the scanned folder (symlinks) are dropped.

Examples

# everything on this branch, quietly, for CI
krypton . --base origin/main --top 0

# clear the worst offenders first
krypton src --level relaxed

# machine-readable, for a hook
krypton src --json

# log progress between iterations
krypton src --history .krypton/history.jsonl
