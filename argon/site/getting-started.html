Getting started

From install to your first scan in five minutes

Krypton is a command-line tool. It reads your source files locally and prints a ranked report.

1. Install

You need Python 3.12 or newer.

$ cd argon
$ pip install .

This gives you the krypton command. The older argon command is installed too and runs the same program. To run without installing, use python -m argon.cli <paths> from the argon folder.

Prefer Docker?

$ docker build -t krypton .
$ docker run --rm -v "$PWD:/repo" krypton .

2. Run your first scan

$ krypton src --top 10

Give it files or folders. Inside a git repository it skips anything your .gitignore ignores, and it skips vendored and generated paths such as node_modules and dist. It scans .js .jsx .mjs .cjs .ts .tsx .mts .cts and .py files.

3. Read the report

The report has a file table, a ranking of the heaviest functions, refactoring hints, and a summary you can paste into a pull request.

ColumnWhat it tells you
branchesDecisions in the file: conditions, loops, cases, catches, boolean operators, ternaries. Counted the way radon and ESLint count them.
nestingHow deeply those decisions are stacked. A nested decision is harder to follow than a flat one.
depthThe deepest nesting in the file. Functions three or more levels deep are marked nested.
effEffective lines. Packing code onto fewer lines does not make it lighter.
ratingKrypton's overall structural rating for the file. Over the limit, the file is flagged.
Purity Score0 to 100 for the whole run. Higher is lighter.

A flagged file means an agent will spend extra tokens reading it and is more likely to break it. The fix is almost always to split a large function by job, not to delete logic.

Exit codes

  • 0: fine.
  • 1: the purity score fell below the failure line.
  • 2: usage error, such as no files or a bad config file.

4. Score only what changed

$ krypton . --base HEAD          # lines changed since the last commit, including new files
$ krypton . --base origin/main   # everything on this branch

Only changed lines count toward the ratings, so old code in the same file does not blame the agent.

5. Put it in your agent's loop

Paste this into CLAUDE.md, AGENTS.md or your tool's rules file:

## Code structure (Krypton)
- After editing source files, run: `krypton <the files or folders you changed> --top 10 --history .krypton/history.jsonl`
- If a file is flagged, or a function you wrote appears with a `nested` flag, refactor it
  before finishing: early returns, small named helpers, one job per function.
- Do not satisfy Krypton by packing code onto fewer lines or by splitting one function into
  many trivial wrappers.
- If a function is marked STALLED, do what its stated reason says before trying anything else.
- Re-run Krypton after refactoring and report the purity score.

A typical session: the agent edits, runs krypton, reads the flagged functions, refactors, and runs it again.
