The compiler for AI agents

Keep AI-written code small enough to read, edit and pay for.

Krypton measures how structurally heavy code is, tells a coding agent exactly what to split, and orders files so your model provider can reuse the prompt cache. It runs locally and needs no network.

What Krypton does

  • Measures every function and file for decisions, nesting, size and coupling
  • Flags what is too tangled and says what to try
  • Tracks whether each run improved it
  • Orders your files for prompt-cache friendly requests

Measure

Scores every function and file for decisions, nesting, size, coupling and trivial wrappers, in JavaScript, TypeScript and Python.

Guide

Hints name the deepest decision and the block to pull out. A progress log shows what improved and what stalled.

Save

An ordering of your files, most stable first, keeps a long shared prefix that providers can cache between turns.

Why it exists

A coding agent re-reads your codebase on every turn, so what the code costs to read is paid again and again. Heavy, tangled functions also make the agent more likely to break something. Krypton is built to sit next to the agent: after each change it runs, shows what got heavy, and the agent splits it before the weight turns into tokens and mistakes.

It is not a linter. Run yours too.
