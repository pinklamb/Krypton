What Krypton is

Krypton is a command-line program that reads your source code and scores how structurally heavy it is. It gives every function and file a number, flags the ones that are too tangled to read or change safely, and tells you which block to pull out. That is all it does to your code. It never edits or runs it, it uses no AI, and it needs no network.

It exists because AI coding agents write quickly but tend to pile up deeply nested, branch-heavy functions. Those are harder for people and for the next agent run to change, and they cost tokens every time the code is read again. Krypton gives you, and the agent, an objective number to hold that code to.

How it fits into your workflow

  1. Scan. Run krypton src. You get a purity score from 0 to 100 and a ranked list of the heaviest functions.
  2. Fix. Hand the flagged functions to your coding agent, or to a person. The hints name the deepest decision and the block to split out.
  3. Gate. Run it in CI or before each commit. A function you touched that is over the limit fails the check, so the agent is sent back to fix it. A progress log shows whether each run improved things.

Three ways to use it

Keep code clean

Score the code and gate changes. In a 20-revision agent test the gate kept the worst function near 12 times the limit instead of about 1,900 times, and cost about 62% more per run.

Cut the prompt bill

Order your files from most stable to most volatile so providers can cache a long shared prefix. The saving depends on your repository: 35% on garth, but a typical gain is about 4 points of cache reuse.

Measure the gap

Compare the structure of AI-assisted code with the rest of your repository, in the same size bands. It reports a difference, not a verdict. On garth and the MCP reference servers there was no per-size difference.

You choose how clean. The strictness setting (--level relaxed, standard or strict) sets how much tangle is tolerated. A relaxed setting lets agent code stay cheaper to produce. A strict one asks for cleaner code and costs more fix rounds. Only the standard setting has been tested with agents.

What it is not

It is not a linter, so run yours too. It is not an AI and it does not rewrite code. It is not a formatter. It is a measurement you can act on.

Why it exists

A coding agent re-reads your codebase on every turn, so what the code costs to read is paid again and again. Heavy, tangled functions also make the agent more likely to break something. Krypton is built to sit next to the agent: after each change it runs, shows what got heavy, and the agent splits it before the weight turns into tokens and mistakes.

It is not a linter. Run yours too.
