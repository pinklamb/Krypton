Krypton · security

HTTPS protects the road. Translating protects the destination.

A secure connection stops anyone listening on the way. It does not change what the receiver ends up holding. Here is what each path leaves on our server.

The demo today server reads your files

Your repositoryOn GitHub. You allow our app to read it, and only read.
→encrypted (HTTPS)
Our serverThe files arrive decrypted, because the demo's server has to open them to build the tree. Held in memory; only the tree goes on to the scoring server.def total(cart, tax): if cart.items: …
→numbers
Your screenScores and hints. The copy is dropped; nothing is written, run or kept.

GitHub does not scramble it for us. It lets our server download the repository over an encrypted connection. The lock ends at our door.

The translated way server never sees code

Your machineA small program on your machine turns each file into a tree of node types and name fingerprints.function_definition identifier 11239872d178729a
→encrypted, translation only
Our serverScores the tree. It cannot read "total", only a fingerprint. No source text arrives to be read.
→numbers
Back on your machineThe names book, which never left, turns fingerprints back into names.

The translation happens before anything is sent, so there is no moment when our server holds your code. Tests send 240 real files through it and fail if any word of source shows up in the request.

Encryption stops eavesdroppers. Translation stops us.

Where this stops. Even translated, the server sees file paths, the shape of each tree, line lengths and sizes. Fingerprints are not salted, so a very common name could be guessed by hashing it. The command line and the translated path do not need GitHub at all; they read the folders you point them at. Status. In the demo, the translation happens on the demo's own server before anything reaches the scoring server, so the scoring server never holds your code. The demo's server does read the repository you connect, in memory, with your own GitHub access: GitHub does the authenticating, Krypton keeps no accounts, and your GitHub token is forgotten when you sign out or after an hour.
