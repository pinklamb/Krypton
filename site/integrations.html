Integrations

Use Krypton where your agent and your team already work

Coding agents

Any agent that can run a command can use Krypton. Add the rules from Getting started to CLAUDE.md, AGENTS.md or your tool's rules file. Use --json if a hook needs structured output.

Coding agentsA few lines in your rules file.
GitHub ActionA check and a comment on every pull request.
DockerOne image; nothing else to install.

Pre-commit and CI

krypton scan . --base origin/main || { echo "Krypton: structure check failed"; exit 1; }

A GitHub Actions job (build the client once and cache it, or keep a built krypton in your image):

name: Krypton
on: pull_request
jobs:
  structure:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v7
        with: { fetch-depth: 0 }
      - run: docker build -t krypton path/to/client
      - run: docker run --rm -v "$PWD:/repo" krypton scan . --base origin/${{ github.base_ref }}

Or use the Krypton action, which sets one Krypton gate line in each pull request's checks and writes the scorecard to the run summary and to one pull request comment it edits on every push, never a second one. See Review.

Docker

Krypton runs from an image you build once from your clone of the repository:

git clone https://github.com/pinklamb/Krypton.git ~/Krypton
docker build -t krypton ~/Krypton/client
docker run --rm -v "$PWD:/repo" krypton scan .

Your project is mounted at /repo. The image has git in it, so --base, order and --log work on your repository's history. For everyday use, the krypton helper from Get started wraps this command, and krypton update pulls the newest code into your clone and rebuilds the image.

On your computer

Two pages open in your browser. Both run on your machine, and neither is hosted anywhere.

  • The settings dashboard. krypton setup --page (or plain krypton, then the link it prints) opens a one-time page at 127.0.0.1:7777 where you click your target, max tries, ask me or auto, and the pull request gate. It stops as soon as you save. With Docker, the port has to be published (-p 127.0.0.1:7777:7777); the helper from Get started does that for you.
  • The review page, styled by themes.md. When the agent is stuck and you chose ask me, your coding agent builds a local page for the ticket, following agent/review-brief.md and looking the way your themes.md describes it (setup writes a starter one). For each stuck function you choose Approve best or Send back. See the preview and Review and setup.
